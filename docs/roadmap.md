# ToolGo Roadmap

## プロジェクト概要

ToolGoは、ブラウザだけで完結する無料ツール集です。入力データは原則としてサーバーへ送信せず、バックエンドを持たない静的WebアプリとしてGitHub Pagesへ公開します。

対象ユーザーは一般ユーザー、エンジニア、デザイナー、学生です。短時間で使える、説明が明確で、軽量なツールを継続的に追加します。

## ゴール

短期的には、5つの代表的なツールを安定して提供できるMVPを公開します。中長期的には、ツール追加の手順を標準化し、既存コードへの影響を抑えながら100〜200以上のツールを運用できるプラットフォームにします。

設計上の優先順位は、保守性、プライバシー、アクセシビリティ、SEO、表示速度、追加開発のしやすさです。

## MVP定義

MVPは、共通UI、静的ビルド、SEOの基本設定、以下5ツール、最低限の品質確認、GitHub Pagesへのデプロイを満たした状態とします。

- JSON Formatter
- Password Generator
- QR Code Generator
- Character Counter
- Age Calculator

広告、ログイン、ユーザーデータ保存、サーバーAPI、複雑な履歴機能はMVPの範囲外です。

## Phaseごとの成果物

### Phase 0: 設計・ドキュメント

成果物は `README.md`、`docs/roadmap.md`、`docs/architecture.md`、`docs/contributing.md`、`docs/mvp.md` です。ツール追加時の判断基準と、MVPでやらないことを明確にします。

### Phase 1〜3: 基盤・デザイン・共通レイアウト

Next.jsの静的export環境、Tailwind CSS、shadcn/ui方針、共通コンポーネント、レイアウト、エラーページ、モバイル表示を整備します。ツール固有のUIはこの段階では作りません。

Phase 1では、Next.js App Router、TypeScript、Tailwind CSS v4、ESLint、Prettier、静的export、GitHub Actions CIの最小構成を実装済みです。`src/app/page.tsx` は基盤確認用のプレースホルダであり、ツール本体はまだ含みません。

Phase 2では、デザイントークン、ライト・ダークテーマ、Button、Input、Textarea、Label、Card、Badgeを実装済みです。共通部品は `src/components/ui` に集約し、トップページで実際の利用例を確認できます。

### Phase 4〜5: 発見性とツール基盤

各ツールのmetadataを一元管理し、一覧ページ、カテゴリ、静的ルート生成、OGP、サイトマップへ接続します。ツールは独立したモジュールとして追加できるようにします。

### Phase 6〜8: MVP完成・公開

5ツールを実装し、入力バリデーション、コピー・ダウンロード、キーボード操作、主要ブラウザ確認を行います。GitHub Actionsで静的ビルドし、GitHub Pagesへ公開します。

### Phase 9〜10: 拡張運用

検索、カテゴリ、関連ツール、共有可能なURL、テスト自動化、パフォーマンス計測、追加レビューフローを整備し、規模拡大による重複や品質低下を防ぎます。
