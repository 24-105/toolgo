# ToolGo Roadmap

## プロジェクト概要

ToolGoは、ブラウザだけで完結する無料ツール集です。入力データは原則としてサーバーへ送信せず、バックエンドを持たない静的WebアプリとしてGitHub Pagesへ公開します。

対象ユーザーは一般ユーザー、エンジニア、デザイナー、学生です。短時間で使える、説明が明確で、軽量なツールを継続的に追加します。

## ゴール

5つの代表的なツールを安定して提供するMVPは完了しています。今後は、ツール追加の手順を標準化し、既存コードへの影響を抑えながら100〜200以上のツールを運用できるプラットフォームとして改善します。

設計上の優先順位は、保守性、プライバシー、アクセシビリティ、SEO、表示速度、追加開発のしやすさです。

## MVP定義

MVPは、共通UI、静的ビルド、SEOの基本設定、以下5ツール、最低限の品質確認、GitHub Pagesへのデプロイを満たした状態とします。

- JSON Formatter
- Password Generator
- QR Code Generator
- Character Counter
- Age Calculator

広告、ログイン、ユーザーデータ保存、サーバーAPI、複雑な履歴機能はMVPの範囲外です。

## Phaseごとの成果物

### Phase 0: 設計・ドキュメント

成果物は `README.md`、`docs/roadmap.md`、`docs/architecture.md`、`docs/contributing.md` です。ツール追加時の判断基準と運用方針を明確にします。

### Phase 1〜3: 基盤・デザイン・共通レイアウト

Next.jsの静的export環境、Tailwind CSS、shadcn/ui方針、共通コンポーネント、レイアウト、エラーページ、モバイル表示を整備します。ツール固有のUIはこの段階では作りません。

Phase 1では、Next.js App Router、TypeScript、Tailwind CSS v4、ESLint、Prettier、静的export、GitHub Actions CIの最小構成を実装済みです。`src/app/page.tsx` は基盤確認用のプレースホルダであり、ツール本体はまだ含みません。

Phase 2では、デザイントークン、Blue/Cyanの配色、ライト・ダークテーマ、Lucide Icons、Button、Input、Textarea、Label、Card、Badgeを実装済みです。角丸と影を抑え、情報密度と可読性を優先した共通部品を `src/components/ui` に集約しています。

Phase 3では、永続左サイドバー、検索・テーマ切替を備えたTopbar、カテゴリ導線、SiteFooter、レスポンシブな`ToolLayout`を実装済みです。`/tools` と `/categories` に共通レイアウトの利用例を置き、パンくず、プライバシー表示、使い方枠、関連ツール枠を確認できるようにしています。

Phase 4では、ページmetadata、canonical、OGP、favicon、`sitemap.xml`、`robots.txt`を静的生成する仕組みを実装済みです。公開URLは`NEXT_PUBLIC_SITE_URL`と`NEXT_PUBLIC_BASE_PATH`で切り替えられます。

Phase 5では、`src/features/tools/registry.ts` と `types.ts` を追加し、5つのMVPツールをmetadataとして登録しました。registryを情報源に、ツール一覧、ツール詳細の静的ルート、SEO metadata、sitemapを自動生成します。Phase 6では各ツールの画面コンポーネントをregistryへ接続し、MVPの5ツールを公開できる状態にしました。

### Phase 4〜6: 発見性とツール基盤・MVPツール

各ツールのmetadataを一元管理し、一覧ページ、カテゴリ、静的ルート生成、OGP、サイトマップへ接続します。Phase 6では、5つのMVPツールをブラウザ内で実装し、入力検証、コピー・ダウンロード、エラー表示、主要なキーボード操作に対応しました。ツールは独立したモジュールとして追加できるようにしています。

### Phase 6〜8: MVP完成・公開

5ツールを実装し、入力バリデーション、コピー・ダウンロード、キーボード操作、主要ブラウザ確認を行います。GitHub Actionsで静的ビルドし、GitHub Pagesへ公開します。

Phase 7では、広告を初期状態で無効にしたまま、共通の広告枠と導入方針を整備しました。広告サービス、広告ID、同意・プライバシー表示は人間側の確認が必要なため、設定が揃うまで実広告を読み込みません。

Phase 8では、`deploy-pages.yml` を追加し、`main`から作成したタグを選んだ手動実行だけで静的exportをGitHub Pagesへデプロイできるようにしました。workflowはタグのコミットが`main`の履歴にあることも検証します。公開前後の確認項目は `docs/release-checklist.md` にまとめています。公開URL、独自ドメイン、利用規約、問い合わせ先などは人間側で確定します。

### Phase 9: 拡張運用

検索、入力途中の候補表示、カテゴリ、関連ツール、SEO導線を実装しました。現在は46ツールを運用できる状態です。ロジック単体テストはVitestで`npm test`から実行でき、新しいツールと代表的な既存ツールのテストを追加しています。今後は共有可能なURL、UIテスト自動化、パフォーマンス計測、追加レビューフローを整備し、規模拡大による重複や品質低下を防ぎます。

MVP後の追加ツール10個と日常生活向け15個の仕様確定・実装は完了しています。給料の手取り計算は計算年を選ばない概算方式とし、制度変更時に前提を見直します。

### MVP後に追加したツール

MVP後の追加ツールは、ツール固有のフォルダ、metadata、ロジック、画面を分け、registryへの登録だけで一覧・カテゴリ・SEO・sitemapへ接続します。すべてブラウザ内で処理し、外部API、ログイン、サーバー保存、入力データの送信は行いません。

追加した10ツール:

- URL変換
- Base64変換
- UUID生成
- ハッシュ生成
- カラーコード変換
- 正規表現テスター
- テキスト差分比較
- CSV・TSV変換
- 画像圧縮
- Markdownプレビュー

日常生活向けに追加した6ツール:

- 給料の手取り計算
- 割り勘計算
- 貯金目標計算
- 税込・税抜計算
- 日付計算
- 単位換算

さらに日常生活向けに追加した4ツール:

- 料理の分量換算
- 睡眠時間計算
- セール価格計算
- 祝日・連休カレンダー

さらに日常生活向けに追加した5ツール:

- 営業日計算
- ガソリン代・燃費計算
- 家計予算計算
- 買い物の単価比較
- 旅行予算計算

さらに、検索意図の明確なツールとして次の5ツールを追加した。

- 画像リサイズ・形式変換
- JSON差分比較
- QRコード読み取り
- 全角半角・文字変換
- パーセント計算

さらに、制度上限を反映して資産形成の目安を確認できるツールとして、NISA積立シミュレーターを追加した。かんたん・詳細モード、参考年率、ボーナス投資、グラフ表示に対応し、制度の前提は `docs/nisa-simulator.md` で管理する。

さらに、課税口座で投資信託を運用した場合の売却時の税金と税引き後受取額を確認できる、投資信託の税引き後シミュレーターを追加した。NISAとは別ツールとし、現行税率の前提と対象外の税務処理は `docs/taxable-investment-simulator.md` で管理する。

さらに、加入区分ごとの掛金上限、受け取り開始年齢、運用資産、掛金の所得控除による税軽減額を確認できるiDeCoシミュレーターを追加した。制度前提と2026年12月予定改正は `docs/ideco-simulator.md` で管理する。

さらに、ブラウザ内で完結し、開発・デザイン作業の具体的な検索意図に対応する5ツールを追加した。

- 写真印刷レイアウト
- VLSMサブネット設計
- Cron式デバッガー
- CSS clamp()生成
- Unicode正規化チェック

さらに、開発・文章作成時の小さな変換作業に対応する3ツールを追加した。

- Unixタイムスタンプ変換
- HTMLエンティティ変換
- 行の並べ替え・重複削除

給料の手取り計算は、計算年を選ばない現在制度の概算方式です。額面月収、健康保険の都道府県支部、扶養人数、年齢、住民税を基本入力とし、詳しく入力する場合は給与明細の社会保険料、所得税、その他控除を任意で指定できます。健康保険組合、賞与、年末調整、各種控除には完全対応せず、結果は給与明細や勤務先の案内を優先します。

追加ツール共通の確認項目:

- TypeScript、共通のToolLayout、共通UI、metadata、FAQを使う
- 空入力、不正入力、境界値、入力上限を処理する
- モバイル幅、キーボード操作、エラー表示を確認する
- ロジックを画面から分離し、外部送信やサーバー依存を追加しない
- `npm run format:check`、`npm run lint`、`npm run build`を実行する
