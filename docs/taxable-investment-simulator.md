# 投資信託の税引き後シミュレーター

## 目的

課税口座で投資信託を積み立てた場合の評価額と、計算した時点で売却した場合の税引き後受取額を見積もるツールです。入力内容と計算結果はブラウザ内で処理し、サーバーへ送信しません。

## 現行制度の前提

2026年8月8日時点で、一般的な公募投資信託を課税口座で保有するケースを簡易的に扱います。国税庁は投資信託を「株式等」に含め、上場株式等（公募投資信託など）の譲渡益を取得費との差額から計算すると案内しています。

- 売却時の概算税率：20.315%
- 内訳：所得税・復興特別所得税15.315%、住民税5%
- 課税対象：評価額が投資元本を上回った部分
- 損失時：課税対象の利益を0円として税金を計算

制度の根拠は、[国税庁「株式・配当・利子と税」](https://www.nta.go.jp/publication/pamph/koho/kurashi/html/04_5.htm) と [国税庁「No.1476 特定口座制度」](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1476.htm) を参照します。税率や制度の扱いは変更される可能性があるため、実際の売却・申告では金融機関の案内や最新の国税庁情報を確認します。

## モード

### かんたん

- 毎月の積立額
- 運用期間
- 想定年率
- 参考年率プリセット

課税口座のシミュレーターのため、NISAの年間投資枠や非課税保有限度額は適用しません。

### 詳細

かんたんモードに加えて、次を指定できます。

- 現在の評価額（任意）
- 現在の取得価額（任意）
- ボーナス投資額と投資月

現在の評価額を入力する場合は、税金の計算に取得価額が必要なため、現在の取得価額も入力します。取得価額が評価額を上回る含み損のケースにも対応します。

入力上限は、現在の評価額・取得価額がそれぞれ1億円、毎月の積立額が100万円、ボーナス投資額が1回100万円、運用期間が50年、想定年率が-99.9%〜100%です。計算結果がJavaScriptで安全に扱える整数範囲を超える場合もエラーにします。

## 参考年率

「全世界株式（オルカン）」「米国株式（S&P500）」「先進国株式」「8資産均等バランス」「国内債券」を、計算用の参考プリセットとして表示します。数値は実績データや将来リターンの予測ではなく、比較しやすくするための仮定です。利用者は年率を自由入力できます。

参考利率は、全世界株式5%、米国株式6%、先進国株式4%、8資産均等バランス3%、国内債券1%です。各タイプの利率が重複しないようにしています。

## 計算ルール

- 月初に積立し、その後に月次の値動きを反映します。
- 年率を月次に換算し、複利で計算します。
- 現在の評価額は開始時点の残高として運用し、現在の取得価額は開始時点の投資元本として扱います。
- これからの積立額とボーナス投資額は、投資元本に加えて計算します。
- 各年の時点で全部売却したと仮定し、`課税対象の利益 = max(評価額 - 投資元本, 0)`、`税金 = 課税対象の利益 × 20.315%` とします。
- グラフでは、税引前評価額、売却時の税引き後受取額、投資元本を比較します。選択した年の税金と税引き後受取額、年ごとの一覧も表示します。

## 計算に含めないもの

次の事項は、税務上の個別事情が大きいため計算していません。

- 分配金の受取・再投資と、その時点の課税
- 信託報酬、売買手数料、その他のコスト
- 他の金融商品との損益通算
- 上場株式等の譲渡損失の繰越控除
- 特定口座の年間取引報告書に基づく取得価額の計算
- 確定申告、控除、所得状況などによる個別の税額

そのため、結果は「同じ条件で運用し、選択した時点でまとめて売却した場合」の目安です。正確な税額や申告要否は、金融機関の年間取引報告書、税務署、税理士などへ確認してください。
