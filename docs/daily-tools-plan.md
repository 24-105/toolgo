# 日常生活向けツール5個の計画

## 方針

MVP後の追加ツールとして、日常的に使う計算・換算ツールを5個追加します。すべて入力データを外部へ送信せず、ブラウザ内で処理します。

給与計算は税制や社会保険制度の影響を受けるため、計算年の選択は設けず、現在の制度を前提にした概算として提供します。正確な給与計算や税務申告には使わず、結果は目安として扱います。

## 実装するツール

| ツール           | slug               | 主な機能                                                                 | 注意点                                                                 |
| ---------------- | ------------------ | ------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 給料の手取り計算 | `salary-take-home` | 額面月収、健康保険の都道府県支部、扶養人数、年齢、住民税から手取りを概算 | かんたん入力と詳細入力を用意し、健康保険組合、賞与、各種控除は別途注記 |
| 割り勘計算       | `bill-splitter`    | 合計金額を人数で分け、余りを1円単位で配分                                | 多めに払う人などの個別配分は対象外                                     |
| 税込・税抜計算   | `tax-calculator`   | 8%・10%の税込価格、税抜価格、消費税を計算                                | 取引ごとの端数処理は別途確認                                           |
| 日付計算         | `date-calculator`  | 日付への日数加算・減算、日付間の日数計算                                 | 土日祝日や営業日は考慮しない                                           |
| 単位換算         | `unit-converter`   | 長さ、重さ、温度、容量を換算                                             | 専門分野固有の定義や測定誤差は対象外                                   |

## 給料の手取り計算の前提

- 額面月収を入力する
- 健康保険の都道府県支部を選択する
- 社会保険料は健康保険、厚生年金、雇用保険の概算率で計算する
- 40歳以上は介護保険料を概算に加える
- 扶養人数を所得税の概算に反映する
- 住民税は利用者が分かる月額を入力する。未入力時は0円とする
- 計算年は選択しない
- 結果には「概算」と表示し、給与明細・勤務先の案内を優先するよう注記する
- 詳細モードでは給与明細の社会保険料、所得税、その他控除を任意入力できる

社会保険料率や税制は変更されるため、公開後も定期的に見直します。制度の確認には[国税庁](https://www.nta.go.jp/users/gensen/index.htm)、[日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/ryogaku/ryogakuhyo/20200825.html)、[厚生労働省](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000108634.html)の最新情報を参照します。
