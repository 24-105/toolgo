# ToolGo MVP Specification

## MVPの共通条件

5ツールは、ブラウザ内で処理し、入力をサーバーへ送信しません。スマートフォンでも操作でき、入力エラーを説明し、主要な処理結果をコピーまたは再利用できる状態を目指します。アカウント、クラウド保存、共有サーバー、広告はMVPの必須条件ではありません。

## JSON Formatter

### 必須機能

- JSON文字列の整形（インデント指定）
- JSON文字列の圧縮（minify）
- 構文エラーの位置または原因の表示
- 入力・結果のコピー
- 入力と結果のクリア

### MVPではやらないこと

- JSON Schema検証
- 大規模JSON向けの仮想スクロール
- ファイルの自動保存やクラウド共有

### 将来追加したい機能

- JSON/XML変換
- JSON差分表示
- ファイルの読み込み・ダウンロード
- JSON Schemaに基づく検証

## Password Generator

### 必須機能

- 長さ指定
- 大文字、小文字、数字、記号の使用設定
- Web Crypto APIによる安全な乱数生成
- 生成結果のコピー
- 設定が矛盾する場合のエラー表示

### MVPではやらないこと

- パスワードの保存、同期、履歴
- サーバー送信や強度判定サービス連携
- 複数ユーザー向けの管理機能

### 将来追加したい機能

- パスフレーズ生成
- 強度のローカル評価
- 除外文字やパターン指定
- 複数件生成とローカルダウンロード

## QR Code Generator

### 必須機能

- テキストまたはURLからQRコードを生成
- 入力変更時のプレビュー更新
- PNGまたはSVGでのダウンロード
- 空入力・長すぎる入力の案内
- 生成データが外部送信されないことの表示

### MVPではやらないこと

- QRコードの読み取り
- ロゴ、複雑な配色、デザイン編集
- クラウド保存や共有URL

### 将来追加したい機能

- 画像アップロードによる読み取り
- Wi-Fi、連絡先、メール等のテンプレート
- 色、余白、ロゴのカスタマイズ
- SVG詳細設定

## Character Counter

### 必須機能

- 文字数、単語数、行数の表示
- 空白を含む・含まない集計
- 入力と結果のクリア
- Unicodeを意識した文字数の扱い
- リアルタイム更新

### MVPではやらないこと

- 文体や感情の解析
- 外部校正・翻訳API連携
- クラウド保存や共同編集

### 将来追加したい機能

- バイト数、段落数、読了時間
- 文字数上限の設定
- SNSやメタ description向けプリセット
- 差分比較

## Age Calculator

### 必須機能

- 生年月日と基準日の入力
- 年齢（満年齢）の表示
- 次の誕生日までの期間表示
- 未来の日付や不正な日付の検証
- タイムゾーンと日付計算のルールを明示

### MVPではやらないこと

- 医療・保険・法的年齢判定への利用保証
- 地域ごとに異なる制度の判定
- 個人情報の保存やアカウント連携

### 将来追加したい機能

- 日、週、月単位の経過期間
- 複数日付の比較
- 記念日・次回イベントのカウントダウン
- ロケール・タイムゾーンの詳細設定
