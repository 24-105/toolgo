## 文書の追加ルール

- 要件は要件・計画に分類する
- 技術構成や責務分担は設計書に分類する
- ブランドやUXの判断基準は方針に分類する
- 開発手順やレビュー基準はルール・手順に分類する
- 新しい文書を追加したら、この一覧とルートREADMEの該当リンクを更新する
- 同じ内容を複数文書へコピーせず、参照リンクでつなぐ
