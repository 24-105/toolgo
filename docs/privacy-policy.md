# ToolGo プライバシーポリシー

制定日：2026年8月4日

公開ページ：[/privacy-policy/](../src/app/privacy-policy/page.tsx)

公開本文は [`src/content/legal.ts`](../src/content/legal.ts) で管理しています。

## 内容

1. アカウント登録やお問い合わせフォームがないため、個人情報を直接取得しません。
2. ツールへの入力内容はブラウザ内で処理し、サーバーへ送信・保存しません。
3. テーマ設定だけをlocalStorageに保存します。独自のアクセス解析用Cookieは使用していません。
4. GitHub Pagesへのアクセスに伴う情報には、GitHubのポリシーが適用されます。
5. 現在は広告を配信していません。Google AdSenseなどを導入する場合は、Cookieや第三者による情報利用を追記してから開始します。
6. お問い合わせ窓口とポリシー変更について定めます。
