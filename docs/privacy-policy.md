# ToolGo プライバシーポリシー

制定日：2026年8月5日

公開ページ：[/privacy-policy/](../src/app/privacy-policy/page.tsx)

公開本文は [`src/content/legal.ts`](../src/content/legal.ts) で管理しています。

## 内容

1. アカウント登録や問い合わせフォームがないため、ToolGoのツール入力から個人情報を直接取得しません。GitHub Issuesへの問い合わせ投稿はGitHubへ送信されます。
2. ツールへの入力内容はブラウザ内で処理し、サーバーへ送信・保存しません。
3. テーマ設定をlocalStorageに保存します。`NEXT_PUBLIC_GA_MEASUREMENT_ID`を設定してGoogle Analyticsを有効にした公開ビルドでは、Cookieなどを利用して閲覧したページ、利用環境、アクセス日時などを収集します。未設定ならAnalyticsスクリプトは読み込みません。
4. GitHub Pagesへのアクセスに伴う情報には、GitHubのポリシーが適用されます。
5. 現在は広告を配信していません。Google AdSenseなどを導入する場合は、広告用Cookie、第三者配信事業者による情報利用、同意方法を追記してから開始します。
6. お問い合わせ窓口とポリシー変更について定めます。
