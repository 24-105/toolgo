# NISA積立シミュレーター

## 目的

NISAのつみたて投資を、入力項目を増やしすぎずに見積もるツールです。入力内容と計算結果はブラウザ内で処理し、サーバーへ送信しません。

## 現行制度の前提

2026年8月8日時点で、成人向けのつみたて投資枠を次の前提で実装しています。

- 年間投資枠：120万円
- NISA全体の非課税保有限度額：1,800万円
- 非課税保有期間：無期限
- つみたて投資枠だけで1,800万円を使い切ることが可能

制度の根拠は、[金融庁「NISAを知る」](https://www.fsa.go.jp/policy/nisa2/know/index.html) と [金融庁「よくある質問」](https://www.fsa.go.jp/policy/nisa2/question/index.html) を参照します。つみたて投資枠の対象商品は、[金融庁「つみたて投資枠対象商品」](https://www.fsa.go.jp/policy/nisa2/products/) の最新一覧を確認します。

制度変更や対象商品の更新があるため、法令・制度に関わる表示は定期的に確認します。売却した商品の簿価分の枠が翌年以降に再利用できる制度は、現在のシミュレーションでは扱っていません。

## モード

### かんたん

- 毎月の積立額
- 現在のNISA運用額（任意）
- 運用期間
- 想定年率
- 参考年率プリセット

### 詳細

かんたんモードに加えて、次を指定できます。

- ボーナス投資額（1回分）
- ボーナス投資の月

入力上限は、現在のNISA運用額が1億円、毎月の積立額が10万円、ボーナス投資額が1回120万円、運用期間が50年です。極端な入力で表示や計算が不安定にならないようにしています。

## 参考年率

「全世界株式（オルカン）」「米国株式（S&P500）」「先進国株式」「8資産均等バランス」「国内債券」を、計算用の参考プリセットとして表示します。数値は実績データや将来リターンの予測ではなく、比較しやすくするための仮定です。利用者は年率を自由入力できます。

参考利率は、全世界株式5%、米国株式6%、先進国株式4%、8資産均等バランス3%、国内債券1%です。各タイプの利率が重複しないようにしています。

## 計算ルール

- 月初に積立し、その後に月次の値動きを反映します。
- 年率を月次に換算し、複利で計算します。
- 現在のNISA運用額は評価額として開始時点の残高に使います。NISAの非課税保有限度額は取得価額ベースですが、過去の取得価額は分からないため、現在額を1,800万円で切らず、これからの積立に対する枠とは分けて扱います。
- 年間120万円または総額1,800万円を超える予定額はNISA対象額から除外します。
- NISA枠から外れる額は、これから予定する積立のうち年間枠または計算上の総枠を超えた部分として表示します。
- 信託報酬、売買手数料、分配金、売却、実際の価格変動、税務上の個別事情は計算しません。

結果には、評価額、現在の運用額、これからの積立元本、運用益、NISA枠から外れた額、年ごとの推移グラフを表示します。グラフ下のスライダーで任意の年を選ぶと、その年の評価額・基準額・運用益を確認できます。
