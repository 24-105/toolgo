# iDeCoシミュレーター

## 目的

iDeCo（個人型確定拠出年金）の加入区分ごとの掛金上限、受け取り開始年齢時点の運用資産、掛金の所得控除による税軽減額を見積もるツールです。入力内容と計算結果はブラウザ内で処理し、サーバーへ送信しません。

## 現行制度の前提

2026年8月8日時点の現行制度を前提にしています。

| 加入区分                      |                                   月額上限 |
| ----------------------------- | -----------------------------------------: |
| 自営業・フリーランスなど第1号 |           68,000円（国民年金基金等と合算） |
| 企業年金なしの会社員          |                                   23,000円 |
| 企業年金ありの会社員・公務員  | 20,000円を上限に、企業年金等との合算で調整 |
| 専業主婦・主夫など第3号       |                                   23,000円 |
| 国民年金の任意加入者          |           68,000円（国民年金基金等と合算） |

企業年金等がある場合は、企業型DCの事業主掛金額とDB等の掛金相当額を合算し、55,000円の範囲内かつiDeCo上限20,000円の範囲で計算します。第1号・任意加入者は、国民年金基金や付加保険料などの金額を68,000円から差し引きます。

制度の根拠は、[厚生労働省「iDeCoの概要」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/nenkin/kyoshutsu/ideco.html) と [iDeCo公式「加入手続きについて」](https://www.ideco-koushiki.jp/start/entry.html) を参照します。

2026年12月1日には、拠出限度額と加入可能年齢の引き上げが施行予定です。第1号・任意加入者の合算枠は75,000円、第2号加入者の共通拠出限度額は62,000円へ引き上げられる予定ですが、このツールは2026年8月8日時点の現行制度で計算します。施行後は最新情報を確認して仕様を更新します。[厚生労働省「2025年の制度改正」](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/nenkin/nenkin/kyoshutsu/2025kaisei.html)

## モード

### かんたん

- 現在の年齢
- 受け取り開始年齢
- 加入区分
- 毎月の掛金
- 想定年率と参考年率プリセット
- 節税額の計算方法
- 年収（会社員等）または課税所得（第1号・任意加入者）
- 扶養配偶者の有無

掛金は0円または5,000円以上、1,000円単位で入力します。受け取り開始年齢は60〜75歳で指定できます。通算加入者等期間が10年未満の場合は受給開始年齢が繰り下がることがあるため、入力した年齢どおりに受け取れるとは限りません。

参考利率は、全世界株式5%、米国株式6%、先進国株式4%、8資産均等バランス3%、国内債券1%です。各タイプの利率が重複しないようにしています。

### 詳細

かんたんモードに加えて、次を指定できます。

- 現在のiDeCo資産
- 扶養親族の年齢（最大8人）
- 企業年金等の月額
- 国民年金基金等の月額
- 毎月の手数料の合計

企業年金等や国民年金基金等の入力欄は加入区分に応じて表示します。

## 税制メリットの計算

標準の「年収・控除から計算」では、年収・控除から拠出前後の税額差を計算します。具体的には次を反映します。

- 会社員等の給与所得控除
- 厚生年金・健康保険・雇用保険・介護保険の概算社会保険料控除
- 所得税・住民税の基礎控除
- 扶養配偶者・扶養親族の控除
- 課税所得に応じた所得税の累進税率
- 住民税10%
- 2037年までの復興特別所得税
- 所得税・住民税の税額差を100円未満切り捨て

会社員等の年収は給与収入として扱い、第1号被保険者・任意加入者の入力は課税所得として扱います。扶養親族は入力時の年齢から毎年1歳ずつ加算し、年齢区分の変化を反映します。

「所得税率を指定（簡易計算）」を選んだ場合は、従来どおり次の式で計算します。

`年間の税軽減額 = 年間掛金 × （入力した所得税率 + 住民税10%）`

課税所得がない場合、掛金の所得控除による税軽減は受けられないことがあります。実際の税額は、所得、他の控除、年末調整・確定申告、加入先の健康保険料率などで変わります。

制度の根拠は、[iDeCo公式「よくあるご質問」](https://www.ideco-koushiki.jp/faq/) を参照します。iDeCo公式は、掛金の全額が所得控除となり、掛金額×（所得税率＋地方税率）分の所得税・地方税が軽減されると説明しています。

## 計算ルール

- 月初に掛金を加え、手数料の合計を差し引いた後、その月の値動きを反映します。
- 年率を月次に換算し、複利で計算します。
- 現在のiDeCo資産は開始時点の残高として運用します。
- 掛金は、受け取り開始年齢と65歳のうち早い年齢まで拠出する想定です。65歳以降で受け取り開始までの期間は、掛金なしで運用のみとします。
- 現行の国民年金基金連合会の掛金納付手数料105円を初期値とし、金融機関等の手数料を含めた合計額を詳細モードで変更できます。運営管理機関によって手数料は異なります。
- グラフは、現在の資産を含む掛金元本と運用資産を比較します。スライダーで年ごとの資産、掛金、年間・累計税軽減額を確認できます。
- 運用計算は従来どおり月初に掛金を加える方式です。比較対象とは積立タイミングが異なるため、運用資産額は一致しない場合があります。

## 計算に含めないもの

次の事項は個別差が大きいため計算していません。

- 受け取り時の一時金・年金にかかる税金
- 退職所得控除、公的年金等控除の具体的な税額
- 退職金や公的年金との重複・受け取り時期による調整
- 障害給付金、死亡一時金、脱退一時金
- 運用商品の信託報酬、商品ごとの値動き、個別の加入資格
- 年単位拠出、掛金の未納・還付、転職時の資産移換

iDeCoの老齢給付金は、原則60歳から一時金または年金で受け取れますが、通算加入者等期間によって開始年齢が変わります。受け取り時は一時金なら退職所得控除、年金なら公的年金等控除の対象になります。正確な税額や加入可否は、運営管理機関、年金事務所、税務署、税理士などへ確認してください。

## 手数料・制度変更

国民年金基金連合会は、2027年1月の掛金引落し分から加入中の手数料を105円から120円へ変更すると案内しています。このツールの初期値は、基準日時点の105円です。利用時点の最新手数料を確認して入力してください。

参照： [iDeCo公式「加入者の手数料」](https://www.ideco-koushiki.jp/start/entry.html)、[iDeCo公式「2027年1月の手数料見直し」](https://www.ideco-koushiki.jp/library/pdf/leaflet202604.pdf)
