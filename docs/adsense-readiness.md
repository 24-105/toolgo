# AdSense審査・運用チェック

更新日：2026年8月10日

この文書は、広告審査中のToolGoで確認する項目をまとめたものです。審査通過や収益を保証するものではありません。

## 現在の状態

- 43個のツールを公開している、ブラウザ内完結・静的出力のWebサイトです
- 本番デプロイ設定には広告のPublisher IDと`ads.txt`を設定しています
- `public/ads.txt`を公開しています
- AdSenseスクリプトは、本番環境で広告設定が有効かつPublisher IDがある場合だけ読み込みます
- 手動広告枠は広告枠IDが設定されている場合だけ表示します
- 広告位置はホーム下部とツール下部に限定し、入力欄や主要操作の間には配置しません
- アクセス解析は測定IDが設定されている場合だけ読み込みます
- シミュレーターの入力値はToolGoのサーバーへ送信しません

現時点では広告審査中です。本番設定上は表示可能な状態ですが、審査・契約・同意要件が確認できるまで、実際の広告表示を継続するかは運用側で判断します。

## 審査前後に確認すること

- AdSenseのアカウント、サイト、審査状況を確認する
- プライバシーポリシー、Cookie、同意取得の要否と文言を確認する
- `https://toolgo.jp/ads.txt`がHTTPSで200を返し、内容がAdSenseの設定と一致することを確認する
- 広告ラベルが表示され、広告が入力欄やボタンに見えないことを確認する
- スマートフォン、キーボード操作、画面幅変更時のレイアウトと広告表示を確認する
- 広告表示によるレイアウトシフト、読み込み速度、コンソールエラーを確認する
- Publisher IDと広告枠IDが実際のAdSenseアカウントの値と一致することを確認する
- 広告設定を変更した場合は、プライバシーポリシーと本番確認結果も更新する

## リリース前の静的確認

```bash
npm run format:check
npm run lint
npm run build
```

本番確認先：`https://toolgo.jp`

- Google Search Consoleでサイトマップ送信状態を確認する
- 主要ページをURL検査し、正規URL・robots・スニペットを確認する
- 広告設定変更後は、モバイル表示と入力操作を再確認する
