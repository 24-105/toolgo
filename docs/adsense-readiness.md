# AdSense申請準備調査・計画

調査日：2026年8月5日

この文書は、ToolGoをGoogle AdSenseの申請前に確認するための作業記録です。AdSenseの審査通過や承認を保証するものではありません。Publisher IDが未発行のため、広告コードと`ads.txt`はこの作業では追加しません。

## 現在の状態

### 構成

- Next.js App Router、TypeScript、Tailwind CSS、Lucide Iconsを使用しています。
- `output: "export"`による静的出力をGitHub Pagesへ配置しています。サーバー、API Routes、Server Actionsはありません。
- ツールは`src/features/tools/registry.ts`を共通の登録元とし、現在20件すべてが`available`です。
- 公開URLは`https://toolgo.jp`です。GitHub Actionsの公開ビルドではcanonical、OGP、robots、sitemapにもこのURLを使用します。

### 公開ツールとカテゴリ

現在のツールは次の20件です。

- 開発：JSON整形、URL変換、Base64変換、UUID生成、正規表現テスター、CSV・TSV変換
- セキュリティ：パスワード生成、ハッシュ生成
- 生成：QRコード生成
- 文章：文字数カウント、テキスト差分比較、Markdownプレビュー
- 計算：年齢計算
- デザイン：カラーコード変換、画像圧縮
- 日常生活：給料の手取り計算、割り勘計算、税込・税抜計算、日付計算、単位換算

### 共通レイアウトとナビゲーション

- `AppShell`がサイドバー、検索付きTopbar、本文、フッターを共通表示します。
- ホーム、ツール一覧、カテゴリ、各ツールページにはパンくずまたは共通ナビゲーションがあります。
- 既存フッターにはホーム、ツール一覧、利用規約、プライバシーポリシーがありましたが、このサイトについてとお問い合わせが不足していました。
- 各ツールには固有の概要、使い方、注意事項、FAQがregistryに登録されています。ただし、詳しい説明が折りたたまれており、関連ツール導線と利用例が不足していました。

### SEO・クローラビリティ

- ページごとのtitle、description、canonical、OGP、Twitterカードは`src/lib/seo.ts`で生成済みです。
- `robots.txt`と`sitemap.xml`はNext.jsのMetadata Routesで生成済みです。現状はホーム、ツール一覧、カテゴリ、規約、プライバシーポリシー、全カテゴリ、全ツールを含みます。
- 404専用ページはありませんでした。
- 静的出力の本番URL設定は`.github/workflows/deploy-pages.yml`にあり、canonicalのURL統一はできています。

### 解析、保存、広告

- Google Analyticsのスクリプトが固定の測定IDで常時読み込まれる実装になっていました。設定の有無を環境変数で管理できるよう見直します。
- テーマ設定だけを`localStorage`へ保存しています。ツール入力と結果はブラウザ内で処理し、サーバーへ送信・保存していません。
- 広告コンポーネント`AdSlot`はありますが、現在の公開ビルドでは`NEXT_PUBLIC_ADS_ENABLED=false`です。AdSenseのスクリプト、Publisher ID、広告枠ID、`ads.txt`はありません。
- Google Search Consoleの所有権確認タグやアカウント設定はリポジトリ内に見当たりません。必要な所有権確認は、運営者がSearch Console側で行う手動作業です。

### 品質上の確認事項

- `TODO`、Lorem ipsum、ダミー広告、`href="#"`、デバッグ用console出力は公開ソースに見当たりませんでした。
- 未実装の`planned`ツールはなく、公開ナビゲーションとregistryの対象は一致しています。
- 主要な入力部品はlabel、フォーカス表示、エラー表示を備えています。検索欄、固定ページ、関連ツール、404の導線を追加・確認します。
- 公開サイトの読み取り確認では、`https://toolgo.jp/`、`robots.txt`、`sitemap.xml`が200で返り、本番canonicalは`https://toolgo.jp`を基準に生成されていました。未作成の固定ページは404相当となる状態でした。

## AdSense承認後に行う作業

1. Googleから発行された正確なPublisher IDと必要な広告枠IDを確認する。
2. 環境変数へ実在する値を設定し、広告を本番公開する前にプライバシーポリシー、Cookie・同意方法、広告配置を更新する。
3. `ads.txt`を静的出力の`public/ads.txt`へ配置し、Googleから指定された内容をそのまま設定する。
4. デプロイ後に`https://toolgo.jp/ads.txt`で内容と200応答を確認する。
5. 広告有効時のレイアウトシフト、速度、モバイル表示、広告ブロッカー時の表示、入力操作への影響を確認する。

- 公開サイトの本番反映後に、主要ページの表示と外部サービスの実際の送信状況を手動で再確認する必要があります。
