# ToolGo 日本語UI文言方針

## 目的

ToolGoの想定利用者は日本語を主に使う人です。そのため、画面上の説明、メニュー、ボタン、状態表示、エラーメッセージは日本語を基本とします。

英語を使うこと自体を目的にせず、利用者が迷わず次の操作へ進める、一般的で具体的な日本語を選びます。

## 基本ルール

1. ユーザーに見える文章は日本語で書く
2. メニュー名は短く、一般的な日本語にする
3. 状態表示は直訳せず、利用者が意味を理解できる表現にする
4. 初めて見る人にも意味が伝わるよう、専門用語には必要に応じて説明を添える
5. 英語と日本語を同じ画面で不用意に混在させない
6. 日本語の文体は簡潔な「です・ます」調を基本とする

## 英語を残してよいもの

次のような固有名詞・標準名・技術名は、無理に翻訳しません。

- ブランド名: ToolGo
- データ形式・規格: JSON、QR、URL、Unicode
- 技術名・ライブラリ名: TypeScript、Next.js、Tailwind CSS、Lucide
- ファイル名、URL、コード識別子、npm script名
- ツールの正式名称として必要な場合の英語名

画面上の正式名称として英語を使う場合でも、説明や操作方法は日本語で補います。

| 避ける表現              | 推奨表現                 |
| ----------------------- | ------------------------ |
| Dashboard               | ホーム                   |
| Tool Library            | ツール一覧               |
| Browse                  | 探す                     |
| Quick access            | よく使うツール           |
| Popular tools           | ツール一覧               |
| View all                | すべて見る               |
| System status           | サービスの状態           |
| All systems operational | 正常に利用できます       |
| Privacy by default      | 入力データを送信しません |
| Available tools         | 利用できるツール         |
| Categories              | カテゴリ                 |
| Coming soon             | 準備中                   |
| Planned                 | 公開予定                 |
| Developer               | 開発                     |
| Security                | セキュリティ             |
| Generator               | 生成                     |
| Text                    | 文章                     |
| Calculator              | 計算                     |
| BETA                    | 試験版                   |

「ライブラリ」「サーフェス」「シェル」「メトリクス」のように、一般利用者には意味が伝わりにくいカタカナ語は、必要性がなければ使いません。

## ツール名の表示

内部のslug、フォルダ名、metadataの英語識別子は保守性のため英語で構いません。画面上の名前は、利用者が目的をすぐ理解できる日本語を優先します。

| 内部識別子           | 画面表示       |
| -------------------- | -------------- |
| `json-formatter`     | JSON整形       |
| `password-generator` | パスワード生成 |
| `qr-code-generator`  | QRコード生成   |
| `character-counter`  | 文字数カウント |
| `age-calculator`     | 年齢計算       |

## 入力・エラー文言

- ラベルは何を入力する欄か分かる名前にする
- プレースホルダーだけに説明を依存しない
- エラーは原因と解決方法を短く示す
- 「Invalid」「Error」などの英語だけの状態表示を出さない
- ボタンは「Submit」ではなく「整形する」「生成する」のように結果が分かる動詞にする

## 実装時の確認

新しい画面やツールを追加するときは、次を確認します。

- 見出し、メニュー、ボタン、状態表示が日本語になっている
- 英語が残っている場合、固有名詞または標準名として必要な理由がある
- 直訳調、不自然なカタカナ、意味の曖昧な表現がない
- モバイル表示でも文章が切れたり読みにくくなったりしない
- `aria-label`、ページタイトル、説明文も日本語になっている
