# ToolGo 自然な日本語の書き方

この文書は、ToolGoの画面文言を追加・変更するAIエージェントと開発者向けのルールです。日本語に翻訳することだけを目的にせず、日本語を母語とする利用者が一度読めば意味を理解できる、自然で具体的な文章にします。

## 基本方針

- 画面の文章は、実際の利用者に話しかける自然な「です・ます」調にする
- 一文を短くし、「何ができるか」「次に何をするか」を先に書く
- 英語の語順や直訳をそのまま日本語にしない
- 抽象的な言葉、宣伝文句、AIが作りがちな大げさな表現を避ける
- 利用者が見た瞬間に意味を理解できる、具体的な動詞を使う
- ボタンは操作の結果を表す動詞にする
- エラーは「何が問題か」と「どう直せばよいか」を一文で伝える

## 避ける表現

次のような表現は、意味が曖昧だったり、機械的に見えたりするため避けます。

| 避ける表現                                   | 言い換えの例                           |
| -------------------------------------------- | -------------------------------------- |
| すばやくアクセスできます                     | すぐに使えます                         |
| 日常の作業を片付ける                         | 作業に使えます                         |
| 正常に利用できます                           | すべてのツールを使えます               |
| 利用できるツール                             | ツール数 / 使えるツール                |
| 入力データはこのブラウザ内だけで処理されます | 入力データを外部へ送信しません         |
| 公開準備中です                               | このツールは準備中です                 |
| 目的に近いツールを探せます                   | 目的に合うツールを探せます             |
| 〜することができます                         | 〜できます / 〜します                  |
| 〜となります                                 | 〜です / 〜になります                  |
| 〜について                                   | 必要な場合だけ具体的な名詞に置き換える |

「高速」「シンプル」「便利」「最適」などの評価語は、具体的な根拠や説明がない限り画面文言に多用しません。

## UIごとの書き方

### 見出し・説明

見出しは短くし、説明では利用者ができることを一文で伝えます。

- 良い例: 「文章の文字数を数えます。」
- 避ける例: 「文章の確認や文字数の計測をブラウザ内で実現できます。」

### ボタン

「送信」「実行」のように結果が分からない言葉ではなく、具体的な操作を書きます。

- 「整形する」「圧縮する」「生成する」「計算する」「コピー」
- 取り消しや初期化は「クリア」または「入力を消去する」

### エラー

原因と解決方法を短く書きます。英語の状態名だけを表示しません。

- 良い例: 「JSONを入力してください。」
- 良い例: 「文字の種類を1つ以上選択してください。」
- 避ける例: 「入力が不正です。」

### プレースホルダー

プレースホルダーは入力例や補足に使い、ラベルの代わりにはしません。サンプルを表示する場合は、初期値として入力済みにせず、薄い文字のプレースホルダーにします。

## 用語の扱い

JSON、QRコード、URL、Unicode、PNGなどの標準名はそのまま使います。ただし、周囲の説明は日本語にします。「metadata」「registry」「コンポーネント」など開発者向けの言葉は、利用者向け画面には出しません。

## AIエージェントの確認手順

文言を追加する前に、次の順で確認します。

1. その文章は、利用者が次の操作を理解するために必要か確認する
2. 主語と動作が明確か確認する
3. 直訳調の表現や抽象的な名詞がないか確認する
4. 同じ画面の他の文言と用語・文体がそろっているか確認する
5. 実際の利用者が声に出して読んでも不自然でないか確認する

迷った場合は、短く具体的な表現を選び、文言のために新しいカタカナ語を増やしません。
